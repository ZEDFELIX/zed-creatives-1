# Legacy ZED Creatives Storefront

This repository is a legacy copy of the ZED Creatives storefront/PWA.

**Canonical ZED Creatives repository:** [ZEDFELIX/ZED-creatives](https://github.com/ZEDFELIX/ZED-creatives)

Do not develop new storefront features here. Keeping this notice prevents future changes from being split between duplicate repositories.

## Legacy features

The old copy contains:
- Marketing pages
- Shop/catalog
- Cart and checkout
- Account pages
- Admin editor
- PWA manifest and service worker
- LocalStorage/Supabase-ready data layer

For current ZED Creatives work, use the canonical repository above.
